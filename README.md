# Витрина продуктовых метрик

SQL-проект по построению ежедневной витрины ключевых продуктовых метрик.

### Что считает витрина
- Daily Active Users (DAU)
- Количество уникальных покупателей в день
- Ежедневная выручка
- Конверсия из активного пользователя в покупателя (%)
- Изменение DAU относительно предыдущего дня
- Отклонение текущего DAU от максимального значения за период

### Использованные техники
- CTE
- `generate_series` для построения календаря
- Оконные функции (`LAG`, `MAX OVER`)
- `LEFT JOIN` + `COALESCE` для корректной обработки дней без данных
- Фильтрация заблокированных пользователей
- Расчёт конверсии

### Логика решения
1. Создаётся календарь дат
2. Рассчитывается ежедневная активность пользователей
3. Рассчитываются продажи и выручка
4. Данные объединяются в единую витрину
5. Добавляются оконные метрики и конверсия

Проект показывает умение строить чистые аналитические витрины и работать с продуктовыми метриками.
