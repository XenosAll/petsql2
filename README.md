# petsql2
активность пользователей связана с покупками и выручкой.

системе сохраняются посещения страниц и заказы, нет единого ежедневного отчёта. м сложно:

находить дни с максимальной активностью;
отслеживать рост и падение DAU;
сколько активных пользователей совершает покупки;
анализировать динамику ежедневной выручки;
корректно учитывать дни, когда посещений или заказов не было.
подготовить SQL-запрос, формирующий ежедневную витрину продуктовых метрик.

Таблица users 
Содержит зарегистрированных пользователей.

Столбец	Описание
id	Идентификатор пользователя
name	Имя пользователя
date_joined	Дата и время регистрации
score	Количество очков опыта
is_blocked	Признак блокировки

Таблица userentry
Содержит посещения страниц пользователями.

Столбец	Описание
id	Идентификатор посещения
user_id	Идентификатор пользователя
page_id	Идентификатор посещённой страницы
entry_at	Дата и время посещения



Таблица orders
Содержит заказы пользователей.

Столбец	Описание
id	Идентификатор заказа
user_id	Идентификатор пользователя
created_at	Дата и время создания заказа
paid_at	Дата и время оплаты, может быть NULL
status	Статус заказа
amount	Итоговая стоимость заказа
